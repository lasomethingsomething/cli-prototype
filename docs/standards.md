### Standards

#### OCI Spec
Artifact format and registry interoperability.

#### OSSF Model Signing Specification
Signing and verification standards for ML models.

#### Model Openness Framework (MOF)
Model classification:
- Class I: Open weights, open training data, open code
- Class II: Open weights, closed training data or code
- Class III: Closed weights

#### SBOM
Software Bill of Materials for supply chain transparency.

#### GitOps
Deployment best practices with Argo CD or Flux.
